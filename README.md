Pig Game

This project implements a web‑based dice game commonly known as the Pig game using HTML, CSS, and JavaScript. It provides an interactive two‑player experience where players take turns rolling a die to accumulate points while managing risk.

Game Rules

The objective is to be the first player to reach a target score (commonly 100 points). On a player’s turn, they may roll the die as many times as they wish. Each roll adds to their current round score, but rolling a 1 will forfeit the accumulated points for that round and end the turn. A player may choose to hold, adding the round score to their global score and passing the turn to the opponent. The game alternates turns until one player reaches the winning score.

How to Run

Clone or download this repository.

Open the index.html file in a modern web browser.

Interact with the game interface to start rolling dice, holding your score, and tracking progress.

Project Structure

index.html – Defines the game’s HTML structure and UI elements.

style.css – Contains layout and styling rules for the game interface.

script.js – Implements the game logic, including dice rolls, score updating, turn management, and UI updates.
